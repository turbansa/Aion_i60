# Проект Aion_i60

## О проекте
Исследование головного устройства (ГУ) электромобиля GAC Aion i60 (комплектация 650 Advanced), получение доступа по ADB, резервное копирование системных настроек и автоматизация установки/обновления/удаления приложений. Анализ работы с машиной по OBD-II, чтение кодов, анализ. Анализ работы по DoIP.

## Автомобиль: GAC Aion i60 650 Advanced (2026 модельный год)
Это пятиместный компактный электрический кроссовер (SUV) на платформе BEV.

### Ключевые технические характеристики
- **Силовая установка**: Один электродвигатель (передний привод, FWD).
    - **Тип двигателя**: Синхронный электродвигатель на постоянных магнитах (PMSM).
    - **Максимальная мощность**: 165 кВт (224 л.с.).
    - **Максимальный крутящий момент**: 240 Н·м.
- **Динамика**:
    - **Максимальная скорость**: 160 км/ч.
    - **Разгон 0–100 км/ч**: ~7.8 секунды (по данным для аналогичной версии).
- **Батарея и запас хода**:
    - **Тип батареи**: Литий-железо-фосфатная (LFP).
    - **Емкость батареи**: 75.26 кВт·ч.
    - **Запас хода (CLTC)**: 650 км.
    - **Быстрая зарядка (30-80%)**: ~0.37 часа (около 22 минут). Поддерживается технология 3C.
- **Габариты и масса**:
    - **Длина x Ширина x Высота**: 4685 x 1854 x 1660 мм.
    - **Колесная база**: 2775 мм.
    - **Снаряженная масса**: 1910 кг.
    - **Объем багажника**: 416 л (967 л при сложенных сиденьях).
- **Подвеска и тормоза**:
    - **Передняя подвеска**: Независимая, McPherson.
    - **Задняя подвеска**: Независимая, многорычажная (пять рычагов).
    - **Передние тормоза**: Вентилируемые дисковые.
    - **Задние тормоза**: Дисковые.
    - **Шины (штатные)**: 215/55 R18 или 225/45 R19.

## Головное устройство (ГУ) и мультимедиа
- **Аппаратная платформа**:
    - **SoC (чип)**: Rockchip RK3588M (в конфигурациях Android Automotive платформа может обозначаться как `rk3588m_car`).
    - **Оперативная память (RAM)**: 12 ГБ.
    - **Постоянная память (ROM)**: 128 ГБ.
- **Экран**: Основной сенсорный дисплей 14.6 дюйма (тип "планшет").
- **Операционная система**: ADiGO (на базе автомобильного Android).
- **Связь и интерфейсы**: Поддержка OTA-обновлений, HUAWEI HiCar, CarLink. Встроенный 4G-модем.
- **Доступ**: Root-права отсутствуют. Основной метод отладки — ADB.

## Диагностические интерфейсы (OBD-II, DoIP, CAN)
*Примечание: Это общая информация по архитектуре, специфичная для Aion i60 может потребовать уточнения на практике.*
- **OBD-II**: Стандартный диагностический разъем для чтения кодов неисправностей и потоковых данных.
- **CAN-шины**: Автомобиль использует несколько шин CAN (например, HS-CAN для силового агрегата и диагностики, другие для кузовной электроники). Для диагностики могут использоваться стандарты ISO 15765-4 (CAN 11bit/500kbaud и 250kbaud).
- **DoIP (Diagnostics over Internet Protocol)**: Диагностика по IP (стандарт ISO 13400). На автомобилях с этой технологией для активации диагностического Ethernet-соединения может использоваться отдельная линия активации (DoIP Activation Line), которая иногда совмещена с LIN-шиной. Для подключения требуется соответствующее оборудование (например, Ethernet-адаптер).

## Окружение разработки
- ОС разработчика: Lubuntu 26.04 (Linux)
- Основной язык для утилит на ПК: Python 3 / Bash
- Инструменты: adb, fastboot

## Правила для ИИ-ассистента
- Объясняй сложные технические шаги простым и понятным языком. Основной упор на Vibe-кодинг.
- Все команды для терминала пиши под Linux (Ubuntu/Lubuntu).
- Никогда не предлагай команды, которые могут удалить системные разделы или заблокировать загрузчик (bootloader) без предварительного бэкапа.
- Учитывай, что ГУ работает на автомобильном Android без root-прав.
- При написании скриптов и команд всегда отталкивайся от технических характеристик, указанных в этом файле (SoC, объем памяти, версия Android/ADiGO, интерфейсы).
